# App DI

Сегмент содержит composition root приложения — место, где создаётся корневой DI-контейнер и связываются токены с конкретными реализациями сервисов.

`createRootDIContainer` знает о составе ServiceDesk и объединяет зависимости из нижележащих FSD-слоёв. Поэтому регистрация конкретных API-клиентов и сервисов относится к слою `app`.

Универсальный React-механизм передачи контейнера (`DIProvider`, контекст и хуки) находится в `shared/di`.
