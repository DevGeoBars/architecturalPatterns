# Shared DI

Сегмент содержит общий механизм интеграции React с DI-контейнером `tsyringe`:

- `DIContext` передаёт контейнер по дереву React;
- `DIProvider` подключает переданный контейнер к дереву приложения;
- `useDIContainer` предоставляет доступ к текущему контейнеру;
- `useService` разрешает зависимость по типизированному токену.

Этот код находится в `shared`, потому что не знает о конкретных сущностях и сервисах приложения и может использоваться всеми вышестоящими FSD-слоями.

Здесь не регистрируются реализации сервисов и не создаётся корневой контейнер. Конкретная конфигурация DI приложения находится в `app/di`.
